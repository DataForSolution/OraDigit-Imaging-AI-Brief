# Imaging Decision Support

## Focus
Correct study selection, protocol selection, indication completeness, appropriate-use logic, contraindication checks, payer/coverage-aware documentation, downstream testing logic and explainable recommendations.

## OraDigit connection
This aligns with reducing imaging-order friction and denials by combining structured rules with language-model support while keeping clinical and payer constraints explicit.

Decision support should never silently replace the ordering clinician or hide the rule that produced a recommendation.
