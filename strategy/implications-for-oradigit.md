# Strategic Implications for OraDigit

## 1. Do not compete only on image classification
The market is crowded with detection, triage and image-processing products. Defensibility is more likely in workflow, quality, decision support and longitudinal analytics.

## 2. Treat PET/CT as workflow plus quantification
High-value areas include protocol consistency, acquisition QA, tracer-specific workflow, quantitative harmonization, longitudinal comparison, response analytics and dosimetry.

## 3. Use CCTA as the reimbursement-aware design model
CMS coverage for defined quantitative coronary analysis demonstrates the need to connect clinical indication, acquisition, interpretation, coding and coverage.

## 4. Build regulation into architecture
Intended use, traceability, versioning, validation, change control and post-deployment monitoring should be designed early.

## 5. Favor assistive systems before autonomous claims
Near-term systems can focus on protocol support, structured information capture, QA, workflow orchestration, analytics and explainable decision support.

## 6. Publish evidence-oriented intelligence
Public notes should clearly separate source fact, clinical context, OraDigit analysis and evidence limitations.
