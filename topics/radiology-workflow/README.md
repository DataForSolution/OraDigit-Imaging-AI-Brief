# Radiology Workflow

Track AI that changes how studies move through imaging operations, not only how pixels are interpreted.

## Core problems
Worklist prioritization, alert fatigue, protocoling, missing clinical information, prior-exam retrieval, structured reporting, urgent-result communication, AI-result routing and quality-control escalation.

## Design principle
The unit of value is not an algorithm output. It is a **completed clinical workflow with fewer delays, errors and unnecessary steps**.
